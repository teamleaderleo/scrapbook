# Knowledge

Scrapbook's canonical technical knowledge lives in [`knowledge/`](knowledge/README.md).

If Leo asks to add, strengthen, connect, review, or traverse the knowledge forest:

1. read [`knowledge/README.md`](knowledge/README.md);
2. read [`knowledge/AGENTS.md`](knowledge/AGENTS.md) before editing;
3. read the relevant trunk and nearby concept nodes;
4. edit the Markdown files directly on a branch;
5. update the local-date entry under [`knowledge/log/`](knowledge/log/) when the work materially changes understanding.

The website is a reader over these files. Do not create a database mirror or a second hand-maintained concept registry merely to make the site render them.

Workbench essays remain under the Workbench publication path. Knowledge nodes are living technical notes: they can begin small, acquire links and examples over time, and change whenever a better explanation survives conversation or real work.
