# Knowledge

Scrapbook's canonical technical knowledge lives in [`knowledge/`](knowledge/README.md).

If Leo asks to learn, review, explore, strengthen, connect, or traverse the knowledge forest and has not already selected a topic, start with [`knowledge/HANDOFF.md`](knowledge/HANDOFF.md). It exists specifically to make a cold start cheap.

Then:

1. read [`knowledge/README.md`](knowledge/README.md);
2. read [`knowledge/AGENTS.md`](knowledge/AGENTS.md) before editing;
3. use [`knowledge/LEARNING.md`](knowledge/LEARNING.md) when choosing a teaching or practice method;
4. read the relevant trunk and nearby concept nodes;
5. edit the Markdown files directly on a branch when understanding materially changes;
6. update the local-date entry under [`knowledge/log/`](knowledge/log/) and rewrite the handoff when the next useful starting point changes.

Reading is the default high-bandwidth intake path. Retrieval, explanation, comparison, changed constraints, and interview-style pressure can happen by voice. Typing is optional unless exact production is itself the skill being practiced.

The website is a reader over these files. Do not create a database mirror or a second hand-maintained concept registry merely to make the site render them.

Workbench essays remain under the Workbench publication path. Knowledge nodes are living technical notes: they can begin small, acquire links and examples over time, and change whenever a better explanation survives conversation or real work.
