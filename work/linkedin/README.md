# LinkedIn profile working copy

This directory is the versioned source for the current LinkedIn cleanup. It is intentionally small.

- [`profile-proposed.md`](profile-proposed.md) is the assembled profile in LinkedIn reading order.
- The section files own the reusable copy for About, Experience, Projects, and Skills.
- [`manual-ui-checklist.md`](manual-ui-checklist.md) owns LinkedIn-only settings, removals, ordering, and final verification.

The repository owns the prose. The live LinkedIn pass was completed on 2026-08-26; LinkedIn still
owns the resulting UI state. Featured was intentionally left empty, and Open to Work preferences
were inspected but left unchanged at the user's request.

Activity is intentionally left empty. This cleanup does not include a post.
