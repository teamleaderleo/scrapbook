# Why this record exists

The cache system was spending storage on entries with almost no reuse path and evicting the entries intended to make the next pull request faster.

The repair makes pull requests consumers instead of producers. Main-branch jobs own reusable seeds, and later cache work can build on one consistent ownership model.
