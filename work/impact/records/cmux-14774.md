# Why this record exists

On 09-25 the picker kept PR work off owned minis that sat idle, mostly because it trusted a stale Blacksmith snapshot and counted jobs that did not exist yet. After the merge, the same population of PR jobs went from 56% (swinging 39% to 85% by half-hour) to about 89% owned, and the Blacksmith queue mostly stopped setting PR queue waits.

The comparison covers the first night after merge and is not load-matched, which the claims say. The rescue's attempt-3 re-runs, fixed separately in cmux#14766, still sent work to Blacksmith in these windows, so this record claims only PR attempt-1 placement and not fleet-wide Blacksmith minutes.
