# Why this record exists

The real VirtualTranscript regression streams updates into a chat and counts row renderers: earlier mounted rows repeat their renders before the change and don't render again after it. The streaming row continues updating.

A first hover shortcut keyed only by row identity missed a newly available footer. A second red/green test makes the cache depend on the rows too. The recut also preserves newer base features that an earlier stale branch would've removed. This is tested rendering behavior, without a full-app frame-time claim.
