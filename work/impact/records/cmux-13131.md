# Why this record exists

The tag name had been treated as a build-cache identity even when the source and toolchain were unchanged. Reusing the warm build tree turned a same-commit tag build from almost sixteen minutes into well under a minute.

The broader matrix also shows the limit: interface changes can still invalidate thousands of Swift files. The optimization preserves that correctness boundary instead of promising every edit will be cheap.
