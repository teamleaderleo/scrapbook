# Why this record exists

The unsigned and final DMGs can differ in signing data while containing the same image. A digest over image data, resource fork and block map lets publication require that the final image is exactly the one tested. Final signature and Gatekeeper checks stay in their own gate.

The source verifies image equivalence on earlier production artifacts and tests failed, skipped and wrong-image smoke results. Its 78 to 106 second critical-path saving is a projection from earlier job timestamps, not a measured new release result. Runner queueing and extra setup can erode it.
