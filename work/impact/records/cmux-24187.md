# Why this record exists

The list already virtualized its views. The expensive part was writing each realized row's frame on the main thread every animation frame. The repair moves those animations to the render server and covers sleep, reuse and movement-disabled cleanup.

[PR 24173](https://redirect.github.com/manaflow-ai/cmux/pull/24173) supplies the real-key interaction harness used on both sides. With ten workspaces, median main-thread busy time over New Workspace at Top falls from 231.0 ms to 162.6 ms. At 200 workspaces, total busy time improves only modestly, frame p95 worsens, and dropped-frame counts don't improve. The shared capture host and mixed results rule out a uniform large-workspace speedup.
