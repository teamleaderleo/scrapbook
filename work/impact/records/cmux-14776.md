# Why this record exists

UI E2E dispatches were the largest remaining source of duplicate app compiles: the PR's own compile admission already builds and signs the cmuxUITests bundle, yet a UI run for the same commit compiled everything again. The one-run comparison shows the removed compile step is most of the difference, about 7 min from run creation to tests when the product already exists.

The headline is observed from one run on each side and on different pools, so it is not a median, and it is the best case: a dispatch that has to wait for an in-flight admission saves less, or can finish later. The volume baseline (117 compiling UI build jobs and 917 compile-minutes in 12.3 h) is what a later after-merge count should be measured against.
