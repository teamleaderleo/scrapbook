# Why this record exists

A page can retain its memory while its scripts stop running. Busy chats, unknown turn state and other ineligible pages stay awake; lifecycle tests cover freezing and thawing.

One paired run with twenty idle chats measured app wakeups at 45.23/s before and 30.60/s after. App CPU was essentially unchanged and renderer footprint didn't improve. The heavier streaming dogfood workload wasn't reproduced by this benchmark, so the result supports lower idle wakeups only.
