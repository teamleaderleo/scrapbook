# Why this record exists

A cache meant to accelerate current main was accumulating older main generations until it could no longer be saved. Once frozen, every scheduled run restored the same stale seed and crossed the same bound again.

One cold build already contains all of current main. Removing the prefix restore keeps the seed smaller, current, and cheaper for every pull request to consume.
