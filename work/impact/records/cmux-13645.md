# Why this record exists

The old trigger looked like a run-level event but arrived every time a job entered progress. One CI run could therefore spawn a fleet of mostly redundant router runs.

The replacement also records a real limitation: GitHub does not emit the chosen requested event for workflow re-runs, so those attempts use the safe hosted fallback instead of pretending coverage remained identical.
