# Why this record exists

The 90-day GitHub Actions export is the stronger economic baseline because it does not depend on annualizing one unusually busy or unusually quiet day.

The export contains **1,966,401 self-hosted macOS runner-minutes over 90 days**. That is **21,848.9 minutes/day on average** or **655,467 minutes per 30-day equivalent month**.

WarpBuild's pricing page, checked 2026-09-23, lists its cheapest macOS runner class at **$0.08/minute**. Pricing every self-hosted macOS minute at only that cheapest rate gives a deliberately conservative floor:

- **$157,312.08 per 90 days**
- **$52,437.36 per 30-day equivalent month**
- **$637,987.88 annualized**

No 12-vCPU premium is included. This means the roughly **$52.4k/month** figure is not a hot-day extrapolation; it is the floor-equivalent average across the entire exported 90-day window.

The separate September 22 accounting measured **18,704 actual macOS runner-minutes/day**, which is consistent but lower than the 90-day average. It remains useful for understanding where the minutes went and which lanes were explicitly 12-vCPU.

This still does not say every self-hosted minute was actually billed to Warp. It says the workload represented at least this much replacement-cost exposure at Warp's cheapest documented macOS rate.
