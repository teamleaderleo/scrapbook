# Why this record exists

A red suite that says only incomplete cannot tell an engineer whether a repair worked or which failures remain. The change preserves the fail-closed path while emitting the complete set of recorded verdicts before returning.

That turns existing evidence back into usable debugging information without weakening the gate.
