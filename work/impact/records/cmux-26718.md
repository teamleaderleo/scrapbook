# Why this record exists

The WebKit oracle uses a 3,000-turn transcript and checks after-paint positions through fractional wheel input. Before the repair it observed 168 blank frames and maximum residual drift of 56.5 px; the repaired version observes no blanks and a 0.5 px maximum. The original 1/64 px assertion failed, and the test now states the half-pixel tolerance the implementation actually meets.

Review exposed additional double-compensation cases for parked readers. Follow-up tests preserve them, including an already-processed upward wheel followed by a shrinking row.

The separate [PR 26745](https://redirect.github.com/manaflow-ai/cmux/pull/26745) immutable geometry primitive merged November 2, but [PR 26833](https://redirect.github.com/manaflow-ai/cmux/pull/26833) production placement integration remained open when checked November 3. Neither its model-only benchmark nor its separately calibrated oracle is added to this result. Native CEF and trusted OS wheel acceptance aren't established here.
