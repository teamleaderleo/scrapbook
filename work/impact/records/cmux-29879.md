# Why this record exists

[PR 27685](https://redirect.github.com/manaflow-ai/cmux/pull/27685) first addressed an agent that kept working through Stop and queued messages that immediately started another turn. Its escalation could then mistake background-agent progress for refusal to stop and kill the entire process group.

The follow-up declares Claude's per-task stop capability and spares the process when background work remains, while keeping the existing escalation for an agent without background work. Unit and integration tests cover both paths.

The trade-off stays visible: an agent that continues producing work beside background tasks won't be restarted, and late calls may reach a later turn. The source also identifies a separate Codex adapter issue; this PR doesn't establish a fix for that adapter's background-agent behavior.
