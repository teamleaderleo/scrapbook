# Why this record exists

Identity versions include an incarnation, so a revoke and regrant back to the same apparent state can't reuse an earlier authorization. Membership leave/rejoin receives the same treatment. Final owner checks stay next to the state they protect.

The public PR reports tests for invalid identity, missing grants, changed membership and changes during reads. Reads across multiple owners aren't atomic; the source retains a limited lease and explicitly acknowledges that remaining window.

This PR adds owner methods without adding public operations or proving every consumer integrated them. It is NEXT implementation evidence, not a claim that the complete Cloud authorization system shipped.
