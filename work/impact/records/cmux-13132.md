# Why this record exists

The app target is roughly 3,700 Swift files, so code placement affects the cost of ordinary edits even when behavior is unchanged.

The measurement also preserves the important limit: a package public-interface change can still recompile importers. The move reduces the routine invalidation domain without claiming the dependency graph disappears.
