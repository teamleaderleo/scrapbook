# Why this record exists

The change repairs a recent startup regression by removing WebKit work from the first-frame path and overlapping the first snapshot request with launch. The immediate-baseline gain and the older-base comparison both matter: reporting only 557 to 478 ms would conceal that most of the gain recovers work recently added.
