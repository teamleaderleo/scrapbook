# Why this record exists

The motivating type error had escaped behind an earlier bundle failure and a formatting failure. The repair runs each check independently and compares each diagnostic, including repeated instances, against the base under its own dependency environment.

A real compiler replay of the escaped error fails with the added diagnostics while reporting shared base errors separately. Unknown failure output and an empty failed diagnostic set count against the change. This improves attribution on a red base; it doesn't claim the base itself is healthy.
