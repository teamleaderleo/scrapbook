Memoize transcript layout by rows, width, measured row heights and renderer registry, avoiding a full conversation layout on scroll-only renders while preserving invalidation when row renderers change.

This PR merged into `feat-cmux-next`. Merge status does not establish a stable release or current deployed behavior.
