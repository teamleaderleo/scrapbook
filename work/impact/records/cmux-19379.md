# Why this record exists

Replace the CLI's duplicate SwiftPM resource bundles with relative links to the app's copies, including replacement of older copies and removal of stale links.

This PR merged into `main`. Merge status does not establish a stable release or current deployed behavior. PR body measures 13 duplicate bundles totaling 3,383,194 bytes (3.23 MiB). A fleet debug build has all 13 as links with no files duplicated below them. An arm64 Release copy produces identical sidebar-template output with copies and links, fails when bundles are absent, and passes strict code-sign verification after re-signing. Developer ID notarization of the linked layout was not run before merge.
