# Why this record exists

The key covers the product's input closure, workflow, toolchain and build decisions. A hit adopts the app and debug symbols from an eligible successful nightly run; a miss, unsafe archive or digest mismatch falls back to compilation. Extraction is staged before replacement.

Signing, notarization and publication still run for the new build. The source reports historical build costs but no retained post-change live reuse result, so no time-saving claim is promoted here. This is distinct from whole-tree fast-tier pass reuse in [PR 23384](https://redirect.github.com/manaflow-ai/cmux/pull/23384).
