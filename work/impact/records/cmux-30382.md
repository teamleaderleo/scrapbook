# Why this record exists

Seeding reconstructs local Git state from a remote baseline plus a bundle, including detached HEAD, sparse checkout and untracked files. Retry identity avoids duplicate jobs; a delta refuses to overwrite a machine whose state changed. Paths stay under the admitted filesystem roots and Git hooks are disabled.

[PR 30633](https://redirect.github.com/manaflow-ai/cmux/pull/30633) adds export with the same deterministic INDEX and WORK snapshots. Unchanged state emits no bundle; changed state exports a diff while excluding ignored output and designated untracked secrets. Tests cover state preservation, stable snapshots, unsafe paths and changes that invalidate a delta.

Both sources are machine-side NEXT merges. Mac-side commands and end-to-end product wiring are separate work, so this record doesn't establish a released round trip.
