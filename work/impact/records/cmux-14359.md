# Why this record exists

This is the app-target twin of cmux#14349, which fixed the same header rewrite for cmuxTests. The macOS 26 pool never showed it, so it only surfaced once PR admissions began overflowing to the macOS 15 pool. That pool's image carries Xcode 26.3 at most, so upgrading Xcode there was not an option. The -driver-show-incremental remarks named the rewritten header directly ("Newer: cmux_DEV-...-ChainedBridgingHeader.h").
