# Why this record exists

Atomic append and acknowledgement writes keep delivery state across restarts. Retrying the same identity and payload returns the original message; conflicting reuse is rejected. Persistence failure leaves memory unchanged, and uncertain post-rename durability can be retried with the same key.

The PR reports mailbox, ownership and protocol regressions. This is the transport persistence layer; later inbox scheduling in [PR 27686](https://redirect.github.com/manaflow-ai/cmux/pull/27686) is another boundary, not a second count of the same end-user capability.
