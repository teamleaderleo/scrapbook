# Why this record exists

A real integration regression puts 300 agent messages into one next-tool-step notice without extra turns. Human prompts keep priority. Notice acceptance, replay, withdrawal and reply behavior are covered, and messages aren't marked noticed before the input writer confirms delivery.

The first implementation covers local plain sends. Superseding sends, team and peer routes, task cards and other named paths still use the older queue in this source. The GUI is separate. This is a scoped NEXT merge, not proof that every route or released UI uses the inbox.
