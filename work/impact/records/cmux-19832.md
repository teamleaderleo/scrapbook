# Why this record exists

Compiling the manifest schema retained duplicated reference subtrees for each long-lived daemon. The library update deduplicates those nodes; a retained-allocation regression fails on the previous dependency and passes after the update.

The PR compares one fleet mini back to back: the same nightly bundle with only cmux-tui replaced. Total physical footprint at one idle workspace falls from 1032 MB to 596 MB. The separate workspace-churn leak remains unresolved in this evidence. This NEXT merge doesn't establish stable-release memory use.
