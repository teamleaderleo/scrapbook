# Why this record exists

A controlled A/B applies only this diff to the same buildable nightly source. Warm idle Cmd-N key-time p50 falls from 67.7 ms to 16.8 ms, while press-to-first-visible-frame p50 moves from 133.8 ms to 105.4 ms. Palette enumeration still runs afterward; the work is deferred, not eliminated.

Quick and cold visible-time samples don't establish an improvement. The current feature-branch base didn't build, so the A/B used a nightly whose touched files matched the PR base. The remaining presentation-to-display gap wasn't explained by this repair.
