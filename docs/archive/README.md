# Archived check-in workflows

The files in this directory preserve the former artwork-first guestbook instructions for historical reference. They are deprecated and are not the active default for agents or automation.

Use [`../agent-check-ins.md`](../agent-check-ins.md) for current check-ins. The standard path derives a deterministic Generation 2 sigil from repository, designation, and description and does not invoke image generation, Drive, raster import, or WebP publication.

The archived guides remain byte-for-byte copies of the former live documents. Reopen them only for a deliberate standalone artwork project after confirming that the current sigil-first workflow is not appropriate.
