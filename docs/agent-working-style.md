# Agent working style

## Write, hand off, leave

For user-directed writing and journal tasks:

- create the requested artifact;
- add or update the relevant repository record or pull request;
- report the current state honestly;
- stop.

Do not sit in the conversation polling CI, deployments, reviews, or other asynchronous checks unless the user explicitly asks for that follow-through.

Pending validation can be named plainly in the handoff. The default is to write, leave the evidence behind, and let the repository continue doing its thing.
