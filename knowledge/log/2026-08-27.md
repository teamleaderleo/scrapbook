# 2026-08-27

Added [Frontier inference economics](../ai-systems/frontier-inference-economics.md) from a conversation about high-volume frontier-model use. The durable correction is to split recorded tokens into fresh prefill, cache-hit context, and generated decode. A blended 10–12B recorded tokens/week with a 2–5% generated share implies roughly 331–992 average decode tok/s; at 95% input-cache reuse, fresh prefill is roughly 785–972 tok/s.

The dated snapshot compares GPT-5.6 Sol, Kimi K3, Qwen3.8 2.4T-A95B, and GLM-5.3-Flash across current Artificial Analysis scores, API-equivalent pricing, parameter footprint, serving requirements, and B300/H200 replacement costs. It records only blended usage and leaves product-surface usage out.

Strengthened [Inference serving](../ai-systems/inference-serving.md) with the throughput-accounting distinction. The new economics node connects that serving model to measurement, latency, memory hierarchy, and agent loops so future model releases can reuse the same derivation with updated inputs.
