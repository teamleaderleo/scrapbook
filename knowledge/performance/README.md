# Machines and performance

Performance work is the practice of explaining where time, memory, bandwidth, or contention actually goes.

Start with [Latency, throughput, and tails](latency-throughput-tail.md). [Profiling the critical path](profiling-critical-path.md) is the discipline of finding the work that owns the result, while [Memory hierarchy](memory-hierarchy.md) explains why equal-looking instructions can have very different physical costs.

This trunk is inseparable from [measurement](../engineering-judgment/measurement.md).
